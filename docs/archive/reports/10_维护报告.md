## 一、用户需求落地

| 需求 | 落地 |
|---|---|
| 主题/壁纸/关于统一按钮风格 | 工具条最终布局：[暂停采集][间隔滑条][提权重启][清理待机缓存][内存加速…][主题…][关于]；「主题…」=外观设置模态（主题三态单选即时生效 + 壁纸选图/遮罩滑条/关闭壁纸/性能提醒 + 恢复默认列宽）；「关于」=关于模态。原"外观"下拉与「?」迷你按钮删除 |
| 关于页运行环境"读不到" | 实证根因：注册表读法本身正确，真正缺陷是**运行时长的函数级 static 在首次打开模态才初始化 → 恒显"0 秒"级**（看起来像读不到）。修复：进程起点稳态时钟 + WindowsBuildText 增加 ntdll RtlGetVersion 兜底 + 函数级缓存消除每帧注册表读取 |
| 网络适配器（参考任务管理器） | 数据层 GetAdaptersAddresses（本机实测 47 适配器）+ 网络页适配器卡片：友好名/类型徽标（以太网/Wi-Fi）/连接状态/链路速度/IPv4·IPv6（含前缀）/网关/DNS/MAC/DHCP/一键复制 IP；回环不显示，断开与虚拟适配器折叠 |
| 性能图表优化 | Phase A 落地：历史 120→600 点、时间窗 60/120/300/600 秒可切（切换不清历史）、字节类 Y 轴 AutoFit 修复削顶、CPU 图可拖拽告警阈值线；Phase B-D（放大详查/队列长度/热图/每适配器吞吐）设计定稿待排期 |
| 全面检查 | V21/V22 双终审 + V23 复核：P0×1（PlotRing offset 语义错位，稳态整窗画旧数据）+ P1×3 全部修复；历史缺陷（确认框点击/壁纸/关于）零复发 |
