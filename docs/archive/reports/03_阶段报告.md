## 遗留风险
- StartupApproved 写入与 UWP State 直写仍属"实验性"（R5 表B#1/#2：系统识别性未完全验证），成功路径有 WARN 日志，备份可逆兜底。
- ETW 事件仅含 PID 无 createTime，PID 复用窗口内流量归因为近似（注释已声明）。
- SATA SMART 依赖驱动支持（USB 桥多数不可用→"未知"，诚实降级）；ACPI 热区/SMART/NVMe 需管理员。
- 服务枚举实测 ~0.28s/次，与其它页共享串行 ops 队列（排队数 UI 显示列入阶段 4）。
