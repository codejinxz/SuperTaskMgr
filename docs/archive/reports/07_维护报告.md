## 二、评审与修复（V15/V16/V17/V18：P0=1、P1=4，全部修复；P2 采纳 8 项）

| 级别 | 问题 | 修复 |
|---|---|---|
| **P0** | **壁纸永不渲染**：绘制调用在 `ui.NewFrame()` 之前，背景绘制列表因 g.Time 戳机制永不被并入 DrawData（V18 以独立探针实证；根因是架构师接线指令的位置错误） | 调用移至 NewFrame 之后（背景列表层级不变），注释记录机理 |
| P1 | CrashLog 漏 Win10/11 标准 `ModuleName/ModulePath` 字段 → 最常见崩溃"模块"列恒为 — | 字段表补齐 + fixture 换真机 schema |
| P1 | PerfCsv 磁盘满后假显"记录中"静默丢行 | Append 查流状态失败即自动停止 + toast |
| P1 | Sensors ReadProp SAFEARRAY 无 VariantClear（管理员机器无界泄漏） | VARIANT 统一清理 |
| P1 | 关闭模态 pending 双击 X 滞留 → 最小化后隐形重开 | 最小化/取消路径清除 pending |
| P2 采纳 | WER 1001 P1 参数兜底、批量清理 toast 回显首个失败+管理员提示、传感器 raw=0 假 0°C 拒绝（"绝不 0 假数据"红线）、双通道 err 聚合、热键 ID 超文档范围、WM_CLOSE"总是退出"时放行外部优雅关闭、壁纸纹理显式释放、死代码移除、关于页/列宽重置等 | 全部落实 |
