# 开发过程归档（Archive）

本目录保存项目开发过程中的**逐轮记录**，不属于产品文档。它们记录了每一轮的实现范围、独立评审发现的问题及其修复证据——如果你想了解"某个设计为什么是现在这样"或"某个缺陷是怎么被发现和修掉的"，这里是原始依据。

当前有效的设计与架构说明请读：
- [../ARCHITECTURE.md](../ARCHITECTURE.md) —— 当前架构
- [../phase/](../phase/) —— 设计规格（选型报告、架构设计文档、功能建议、图表设计、内核调研）
- [../HANDOVER.md](../HANDOVER.md) —— 交接文档
