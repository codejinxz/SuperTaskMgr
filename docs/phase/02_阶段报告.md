# 阶段 2 报告：核心功能开发

## 完成内容
- **构建体系与骨架**（架构师）：CMake 四目标（stm_core/stm_collect/stm_ops + SuperTaskMgr/stm_selftest）；vendoring imgui v1.92.9 + implot v1.0（SHA256 记录于 third_party/SHA256SUMS.txt）；契约头冻结机制；公共库（Log/Str/Err/Cfg/Jobs/Notifications/FsUtil/Privilege/ProtectedList）；应用壳（Win32 窗口/D3D11 含 WARP 兜底/ImGui+中文字体/主题/单实例/会话交接/提权重启）；自测框架。
- **D1 采集层**：NtQSI(SystemProcessInformation) 主路径 + 6 项自校验门（CPU 时间/WS/IO/句柄/线程/私有工作集，失败自动降级 Toolhelp+PSAPI 兼容模式）；(pid,createTime) 身份差分；每 5 tick 切片刷新补充信息（路径/提权/UWP/WOW64/服务宿主/窗口标题）；SystemCollector（每核 CPU、提交/内核池、磁盘、网卡速率回退守卫）；GpuCollector（DXGI+GPU Engine，虚拟适配器双重身份信号过滤）；私有工作集走 NtQSI WorkingSetPrivateSize（tick p50 ≈11-12ms，达标 ≤15ms）。
- **D2 操作层**：身份重验（createTime ±1s）→ 保护名单硬门（SystemRoot 路径限定防同名校绕过）→ SeDebug 按需启用用后即释；两段式树杀（Plan/Execute，执行时重快照+逐成员重验+保护成员跳过报告，实测 cmd→ping 树终止成功）；TrimWorkingSet；PurgeStandbyList（SeProfileSingleProcessPrivilege）；WinVerifyTrust 签名（catalog 路径+VERIFY/CLOSE 配对+缓存）；DetailsProvider（签名/命令行 PEB 读/用户名/GDI+USER/模块，走 JobQueue）。
- **D3 界面层**：进程页全量表（13 列、用户触发排序+每 tick stable_sort、过滤、列宽持久化、ProcKey 选中跟踪、徽标、诚实 "—"）；性能页 ImPlot 120s 四块曲线；详情面板（签名/命令行/用户名/GDI+USER/父进程跳转/版本信息）；模态确认框（两段式树杀含"预计 N+1 个"、取消按钮首位+破坏性按钮 NoNav）；toast 通知；托盘；状态栏自省（帧耗时/tick p95/兼容模式警示）。
- **验证**：构建 0 错误 0 警告（/W4 全仓）；stm_selftest 26/26 双轮稳定；GUI --smoke 120 通过；SuperTaskMgr.exe 单文件 1.4MB。
