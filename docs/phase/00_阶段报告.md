## 遗留风险
- ImGui 1.92+ 动态字体/渲染器 API 与旧教程不兼容，开发须对照当前官方文档（vendoring 固定版本缓解）。
- 中文 IME 在 ImGui 输入框的边角问题：阶段 2 以 spike 实测定级，必要时输入场景退化为复制粘贴/过滤器关键字。
- 目标机假设：仅保证 Win10 21H2+ / Win11 x64；24H2 的 EnumDeviceDrivers 权限变化已纳入设计。
- 未签名 exe 的 AV/SmartScreen 告警（README 声明）。
