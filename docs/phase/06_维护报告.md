# 维护轮报告（06）：系统进程区分 + 传感器多值 + F4 推荐功能落地

- 触发：用户三项需求——①区分系统进程的按钮 ②传感器同类多值全部展示/可选 ③完善 F4 推荐功能；并要求 subagent 排查遗漏 bug 直至终评审完成。
- 执行：契约先行（ops/ProcessControl.h、ops/CrashLog.h 由架构师冻结；Sensors.h 授权增量扩展）→ G-A/G-B/G-C 三路并行开发 → 集成 → V15/V16 双终审 → 3 项 P1 修复 → 复验。

## 一、交付内容

| 功能 | 说明 |
|---|---|
| 区分系统进程 | 工具条三态（关闭/高亮/只看用户进程）；ProcKind 分类器（关键>服务宿主>UWP>Windows>User，空路径保守名表），配色+图例；cfg 持久化 |
| 传感器多值 | ACPI 热区**逐实例**、NVML 逐卡逐传感器（温度/慢速阈值/功耗/双利用率/风扇）、逐盘 SMART 细项、每核频率占用、每适配器吞吐、电池、内存/分页池；**详细模式**开关逐条展示；修复一处 WMI denied 被误报 NoHardware 的诚实性缺陷 |
| 挂起/恢复+优先级/亲和性 | NtSuspend/Resume（动态绑定+文档化逐线程回退）、优先级六档（Realtime 双警示）、亲和性掩码校验；保护名单硬拒四操作；全部二次确认+身份重验 |
| 崩溃记录页 | 事件日志 1000/1001/1002 最近 200 条（免管理员），时间倒序，只读 |
| 窗口管理页 | 顶层窗口枚举/前置/置顶/最小化/温和关闭（WM_CLOSE+确认+执行前句柄与 PID 复核） |
| 进程树视图 | 平铺/树形切换：DFS+兄弟按排序键、孤儿与 PID 复用校验、与过滤叠加 |
| 跨页联动 | 网络/服务页 ↔ 进程跳转、服务宿主模态（同 PID 服务列表） |
| 性能 CSV 导出 | captures 目录 1Hz 记录，写失败自动停止+toast；启动清除残留开关 |
| 全局热键 | Ctrl+Alt+M 呼出/隐藏（默认关，注册失败如实回滚） |

## 二、评审与修复（V15 新功能正确性/安全、V16 回归与泄漏：P0=0）

| 级别 | 问题 | 修复 |
|---|---|---|
| P1 | CrashLog 达到 maxCount 截断时批内 EVT_HANDLE 泄漏（每次刷新最多 15 个） | G-A：EvtBatchGuard RAII 全路径补关 |
| P1 | PerfCsv 磁盘满后假显"记录中"静默丢行 | G-C：Append 查流状态失败即自动停止+toast |
| P1 | Sensors ReadProp SAFEARRAY 无 VariantClear（管理员机器上无界泄漏） | G-B：VARIANT 统一清理，无双释放 |
| P2 | WMI 基础设施失败误报 NoHardware（诚实性） | G-B：三分判定（NeedAdmin/WMI 不可用+notes/NoHardware） |
| P2 | WM_CLOSE 句柄复用竞态、热键 ID 超文档范围、perfCsvWanted 死键、亲和性模态失败态"永久查询中" | G-C：IsWindow+PID 复核、0xB34D、启动清键、三态+重试 |
