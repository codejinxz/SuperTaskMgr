# 维护轮报告（12）：兼容模式诊断体系 + 连接级网络监视器 + PawnIO 内核温度/风扇/电压

- 触发：用户①兼容模式原因可点击说明/可解决/可上报 ②Wireshark 式网络监视（协议/目标/内容，要求补全）③授权调用内核（能力优先）。
- 执行：三轮 subagent 流水线。第一轮 D1（兼容诊断）∥ D2（监视器核心）∥ D3（内核路线调研+探测尖峰）；第二轮 D5（监视 UI）∥ D6（PawnIO 实现与真机验证）；第三轮 V24/V25/V26 三终审 → 三路修复 → 终验。

## 一、兼容模式：可解释、可重试、可上报（D1）

- **逐项诊断报告**：6 项自检（CPU 时间/工作集/IO/句柄/线程/私有工作集）每项输出 测量值对比 明细；状态栏"兼容模式"可点击 → 说明模态（逐项绿勾红叉表 + 触发原因分类：系统更新改结构/安全软件挂钩 NtQSI/系统限制 + 降级影响清单）。
- **自检加固（消除误报）**：参考进程重选（自身优先、存活>60s 系统进程）+ 失败自动重试 2 次 + 连续 2 轮全过才放行——瞬时扰动（参考进程退出/采样噪声）不再误降级；实机日志证实加固路径真实工作。
- **可重试可上报**：状态栏一键重试（代际计数器防竞态，成功自动退出兼容模式）；"复制诊断报告"生成系统版本+应用版本+逐项结果纯文本（剪贴板+logs 落盘，明示不自动上传）。

## 二、连接级网络监视器（D2 核心 + D5 UI）

- **连接事件流**（免管理员）：1s 差分连接表 → 新建/断开/状态变化事件（进程、协议、本地/远程、状态中文）；环形 8192 保新弃旧 + 丢弃计数诚实展示；过滤（进程/远程/协议/事件类型）+ 暂停/清空/CSV 导出。
- **按远程端点聚合**（需管理员 ETW）：按 (进程, 远程 IP:端口, 协议) 聚合收发字节，Top20 远程目标表（服务名/进程）；**本机实测修复后 20/20 事件字段 100% 命中**（含 112.95.0.85:443 HTTPS 正确解析）。
- **DNS 解析记录**（需管理员，实验性）：实测解码真实查询（www.msftconnecttest.com 等，pid 归属正确）；解析失败自动禁用并黄字提示。
- **诚实边界**：UI 常驻说明"连接级监视，不捕获通信内容"（抓载荷需 Npcap，见下）。

## 三、PawnIO 内核增强（D6，真机验证通过）

- **自研最小 IOCTL 接口**（无 LGPL DLL 依赖）：加载官方签名模块（IntelMSR/LpcIO，SHA-256 白名单钉扎）→ 执行。
- **真机实测（i5-12600H，PawnIO 2.2.0 官方签名安装，签名校验通过后才装）**：16 逻辑核每核 DTS 温度（负载 46-88°C，轻载 46-65°C，与 ACPI 机身温度交叉核对合理）；识别 ITE IT8613E，9 路电压；风扇因笔记本 EC 调速诚实无读数。
- **安全加固（V26）**：SuperIO 进入/退出序列 RAII 配对（杜绝残留配置态）；模块哈希白名单；PawnIoShutdown 生命周期。
- **集成**：传感器页 CPU 组逐核"CPU 核心 N（DTS）"（真实核号，滤除不漂移）、LpcIO 风扇真实读数、电压入"其他"组；未安装 PawnIO 时全部诚实降级并给安装指引。
- **README 已更新**：内核能力声明（opt-in、不捆绑不分发、只读、哈希校验）。
