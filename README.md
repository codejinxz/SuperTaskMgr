# SuperTaskMgr（Windows 超级任务管理器）

面向系统管理员的本地进程/系统监控与维护工具。参考 Process Explorer / Process Hacker 的能力集，使用纯 Win32 + Dear ImGui + D3D11 + ImPlot 自绘 UI 与纯 C++ 采集层，构建产物为**单文件、零第三方 DLL、静态 CRT** 的便携 exe（约 1.7MB）。

> 定位声明：本工具面向管理员自用。UI 为 ImGui 自绘（非原生控件观感，无屏幕阅读器/无障碍支持）；所有"拿不到的数据"如实显示 `—` 或"需提权/需驱动"，**绝不显示假数据**。

## 功能

- **进程**：全量进程表（CPU / 私有工作集 / 提交 / 磁盘 / 网络 / 硬故障 / 句柄 / 线程 / 上下文切换 / 提权-UWP-WOW64-服务-保护徽标），1 秒级刷新、排序、过滤、列宽持久化；**平铺/树形视图切换**；**区分系统进程**三态（关闭/高亮/只看用户进程：关键进程/Windows 系统进程/服务宿主/UWP/用户应用分类着色）；详情面板（路径/签名/命令行/用户名/GDI+USER/父进程跳转/**已加载模块列表+按模块签名**）。
- **进程控制**：挂起/恢复（保护名单硬拒）、优先级六档（Realtime 红字警示）、CPU 亲和性逐核设置，全部二次确认+身份重验。
- **崩溃记录**：事件日志中的应用错误(1000)/挂起(1002)/WER 报告(1001)最近 200 条，免管理员。
- **终止**：单进程 / 进程树（两段式确认，执行时重新快照、逐成员重验身份、保护成员跳过并报告）；自动启用 SeDebugPrivilege（用后即释）；服务宿主进程红字警告。
- **内存清理**：释放进程工作集 / 清理系统待机缓存（诚实文案：只清系统缓存，不回收进程内存；伴随缺页代价，性能页可见 Hard Faults 抖动）。
- **性能**：CPU（总+每核）/ 内存 / 磁盘 / 网络 120s 实时曲线；GPU 适配器与按进程占用（PDH GPU Engine，虚拟显示适配器已过滤）。
- **网络**：TCP/UDP 连接表（本地/远程/状态/PID/进程名）；可选 **ETW 按进程流量统计**（需管理员，仅本机统计、不上传）；跨页联动（连接/服务 ↔ 进程跳转、服务宿主列出同 PID 服务）。
- **窗口**：顶层窗口管理（前置/置顶/最小化/温和关闭，关闭需确认且执行前复核句柄有效性）。
- **启动项**：注册表 Run/Run32、启动文件夹、计划任务（登录/启动触发）、UWP StartupTask 四源枚举与启用/禁用；**写前自动备份**（时间戳保留历史，计划任务同时备份 XML）。
- **服务与驱动**：服务枚举/启动/停止（依赖树警告）、驱动列表与按需签名校验。
- **传感器**：CPU 每核频率与占用率、**ACPI 热区逐实例温度**、SMART 磁盘健康细项（NVMe 备件%/磨损%/通电时长、SATA 温度）、GPU 逐传感器展开（温度/功耗/利用率/显存，NVML 存在时）、每适配器网络吞吐、电池、内存/分页池、风扇（诚实标注"需要驱动支持"——本应用不内置内核驱动）。各分组**可勾选显示**+**详细模式**（逐条展示全部读数实例）；可选接入 **LibreHardwareMonitor 数据源**（默认关：自行运行 LHM 并启用其 Web 服务器，本工具仅读本机 127.0.0.1，实现 HWiNFO 级覆盖且不随包分发驱动）。
- **外观与关于**：主题三态（深色/浅色/跟随系统，实时响应系统切换）；**自定义壁纸**（PNG/JPG/BMP，可调遮罩浓度；选项旁常驻性能开销提醒）；**「?」关于对话框**（版本/发布时间/仓库链接/运行环境）。发布前修改 `src/app/AboutInfo.h` 顶部的三个常量即可（版本号/日期/仓库地址），详见下方"发布说明"。
- **性能与效率**：性能页 **CSV 记录导出**（captures 目录，1Hz）；**全局热键 Ctrl+Alt+M 呼出/隐藏**（默认关，可在设置开启）；阈值告警（CPU/内存，托盘气泡）；**一键内存优化**（Top10 高占用勾选批量释放工作集 + 可选清待机缓存，诚实文案）；标题栏 X 可选"退出/最小化到托盘"（可记住选择）。
- **进程详情**：签名/命令行/用户名/GDI+USER/父进程跳转，以及**已加载模块列表**（点击任一模块即时校验签名）。
- **其他**：性能阈值告警（托盘气泡，默认关）、托盘、暗色主题、中文 UI、提权重启（会话状态交接）、采集自省状态栏。

## 构建

环境要求：Windows 10 21H2+ / Windows 11 x64；VS2022 Build Tools（含 MSVC、CMake 组件）。无其他依赖（imgui/implot 已 vendoring，见 `third_party/SHA256SUMS.txt`）。

```bat
scripts\build.bat            :: Release（默认）
scripts\build.bat Debug      :: Debug
build\Release\SuperTaskMgr.exe        :: 主程序（单文件便携）
build\Release\stm_selftest.exe        :: 自测（40 项，--json 输出）
```

CI 冒烟与自动化回归：`SuperTaskMgr.exe --smoke N`（无交互渲染 N 帧退出，覆盖全部页签）；`--autotest kill|tree|startup`（程序化走完整终止/禁用链路）；`--autotest dialogclick`（**真实 ImGui 输入管线**注入鼠标点击确认按钮并断言生效，含"模态单帧化"旧缺陷哨兵）。全部 exit 0 为通过。

## 权限与隐私声明（重要）

- **默认以普通权限启动**；需要提权的功能有明确徽标，一键"以管理员身份重启"（UAC），会话状态自动交接。
- 本工具**不联网上传任何数据**、无监听端口、不写自启动、不留常驻服务；ETW 网络统计为显式开关（默认关）、会话名唯一，正常退出即清理（**例外**：进程崩溃时管理员权限下已开启的 ETW 会话可能残留约 4MB 非分页池，直至系统重启或下次同名实例启动时清理——已知限制）。
- 破坏性操作（杀进程/树、释放工作集、清待机缓存、禁用启动项、停服务）全部**二次确认**；系统关键进程（csrss/lsass/wininit 等）受**双层保护名单**硬拒绝。
- 未签名 exe：SmartScreen/杀软可能提示"未知发布者"——本工具以本地构建分发，不申请代码签名；所有操作写本地日志（`%LOCALAPPDATA%\SuperTaskMgr\logs`，可审计；日志不记录命令行/窗口标题）。

## 已知限制（诚实清单）

- 需要管理员的能力（提权后可用）：他人进程的路径/内存/命令行、SMART、ACPI 热区温度、ETW 流量、服务启停、HKLM 启动项、计划任务系统文件夹、模块列表；驱动列表在 Windows 11 24H2+ 需要提权（系统行为）。
- **不内置内核驱动**：CPU 每核温度、主板风扇转速无法在用户态获取，界面如实标注"需要驱动支持"（引入 WinRing0 类驱动的安全风险见 `docs/phase/00_技术选型评估报告.md`）。
- GPU 温度需要厂商运行时（NVIDIA=NVML；AMD/Intel 暂未接入）。
- StartupApproved / UWP StartupTask 的注册表语义为社区考证+本机实测（非官方文档化），禁用操作有备份可逆兜底，标记为"实验性"（日志 WARN）。
- PDH 部分计数器（如 `\Memory\Hard Faults/sec`）在个别系统缺失，显示 `—`。
- ImGui 自绘 UI 的 IME/无障碍限制；中文列排序为码点序。
- 空载内存 ≈124MB（D3D11 运行时+驱动+字体图集基线，30 秒零增长；预算与证据见 `docs/phase/01_架构设计文档.md` §10）。

## 发布说明（如何填版本号/仓库地址）

编辑 **`src/app/AboutInfo.h`** 顶部的三个常量后重新构建即可：
- `kAppVersion`：版本号（显示在"关于"对话框与窗口标题）；
- `kBuildDate`：发布时间（如 `L"2026-09-19"`，留空则不显示该行）；
- `kRepoUrl`：GitHub 仓库地址（如 `L"https://github.com/you/SuperTaskMgr"`，留空则隐藏链接行；关于页点击后用系统浏览器打开）。
建议同步更新 `src/app/app.manifest` 中的 `assemblyIdentity version`。
